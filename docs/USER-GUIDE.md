# 使用说明

## 打开和安排

双击桌面 **间序 - AI日程**。默认本地地址为 http://127.0.0.1:4317 。首次打开没有预填任务。

日历从今天开始显示连续七天，左右箭头逐日移动，日期按钮选择任意起点。按小时纵向滚动，到边界继续滚动可前后移动日期；拖动到左右边缘也可平移。双击日历空白处创建任务。

- 新建待办或固定事件，项目用于归类小任务，也支持独立事项。
- 待办可只填名称和截止日期，之后拖动清单右侧把手安排时间。
- 拖动按半小时吸附；编辑区支持09:15等精确时间，结束时间可填24:00。
- 冲突位置灰色打叉，不能放下。课程勾选每周重复并填写学期结束日期。
- 点击时间块省略号编辑；重复课程可选仅本次／本次及以后。
- 待办到期显示待确认，可完成或记录部分进度后退回清单，不自动顺延。
- 固定事件不需要逐次打勾。08点以前的事项可从日历上方范围外条目进入。
- 顶部撤销或非输入框内Ctrl+Z可撤销最近20次日程操作。

## 配置模型

点击左下角齿轮。图片／对话和语音转写分别配置：

- 服务地址：兼容接口根地址，通常到 `/v1`，不要填到 `/chat/completions`。
- 模型名称：服务商实际提供的模型ID。
- API Key：在网页自行填写，由Windows当前用户保护后保存在本机，不能上传GitHub。

保存后测试文字连接，选一张图片测试视觉。模型必须实际支持图片输入；有效Key不等于具备图片能力。语音需要兼容 `/audio/transcriptions`，可配置不同服务。

远程服务使用HTTPS，显式配置的本机服务可使用HTTP。没有模型也可手工使用日历。

## 图片与草稿

将图片拖到右侧输入框、粘贴截图或点击图片按钮。支持PNG／JPEG／WebP，每张8MB以内，每次最多4张。输入说明后发送。

AI先生成可编辑草稿；点击“编辑内容”修改，勾选所需条目后“采用所选”。采用前正式日历不变。草稿显示“编辑中／保存中”时请稍候再关闭。

日历有新变化时先重新核对草稿。冲突要修改或取消选择；关联项目、任务和时间块需一起采用。首版不联网检索资料。

## 口述与跟进

点击麦克风开始，停止后转写，最多2分钟。可以取消录音。文字进入输入框，修改后发送，不直接执行任务。首次需要麦克风权限；网络转写会将音频发给所配置服务。

可说“还没想好，两天后再问”，明确跟进时间后采用。也能在任务详情点“稍后跟进”。网页开着时显示跟进卡片，关闭后不提醒，重开补显示。跟进不会自动给任务排期。

## 数据与恢复

默认数据目录 `%LOCALAPPDATA%/PersonalAIPlanner`，与仓库及测试库隔离。设置可导出和恢复备份；包含日程、对话、草稿及图片，不含模型配置和密钥。

恢复会替换现有内容，并先在数据目录的 `backups` 中生成恢复前备份。需要原记录时导入该备份；恢复不是普通撤销。恢复请求上限200MB。

关闭网页不删数据。设置中的“退出本地服务”停止服务；再双击快捷方式启动。

## 当前边界

SQL学习已开放，英语为预留入口。支持同一Wi-Fi内手机电脑共用数据，时区跟随电脑。跨午夜时间块需拆成两条。不包含外网访问、联网搜索、语音播报和关闭网页后的通知。

适配器已通过隔离模拟协议测试；真实图片质量和麦克风转写，需要使用你的实际模型配置验证。

## SQL学习工作台（2026-09-21）

点击左侧书本图标进入独立SQL页面。第一版有6道基于虚构用户、订单、访问数据的练习：筛选、汇总、关联、无付款用户、转化率和窗口排名。

- 左侧选择题目，右侧查表结构或展开示例数据。
- 中间写SQL，点击“运行”或Ctrl+Enter查看结果；“提交检查”会用示例和变体数据检查列名、值及题目规定的排序。通过表示通过这些练习检查，不等于完整能力认证。
- 分步提示逐条展开，使用数量记录到本次运行/提交记录。
- “分析我的SQL”调用设置中的模型，给思路提示；它与确定性判题分开，不会替你提交。
- 代码自动保存，本题记录可恢复以往代码。学习数据随备份导出，最多保留最近500次运行和提交。
- 使用SQLite方言；练习数据库与日程数据库分离，只允许读取示例数据，每次运行重建，5秒超时、最多500行。不支持导入个人数据库。
- 英语页面仍为预留功能。

日历修复：撤销“采用草稿”会恢复待确认草稿，可修改后重新采用。

## SQL总览与学习规划

进入SQL默认显示总览和8章目录。总预计48小时属于初始课程估算（视频/练习/复习），不是掌握保证。周期按天计算，月份快捷按钮按30天近似；公式为每周小时=48×7÷天数，每日均摊=48÷天数。两个滑块以最后操作为准，先点“预览每日任务”，核对日期、时段与内容，再点“确认采用并写入日历”。剩余章节按30分钟单位拆成讲解、练习、复习任务，优先18:00—22:00、备选08:00—24:00空闲时间，周四不安排，避开已有日程。长周期均匀分摊，排不下的进入待办。当前滑块仍按整条48小时路线换算；已确认章节和保留任务的学时不重复生成，因此剩余实际新增学时会更少。采用后章节截止显示实际任务日期。重新排期替换未来尚未开始的学习安排，保留已完成、到时待确认及退回清单的任务。采用支持日历撤销，学习计划同时恢复。

每章有简介、目标、预计时长、截止日期、B站视频主题和外部练习。确定使用DBeaver Community作为客户端、PostgreSQL作为数据库；官网下载入口已列出，尚未安装工具。练习数据可下载为SQL脚本，请在新建空库导入，不会自动覆盖同名表。原网页执行器保留为“可选网页校验”，使用SQLite，不能将所有PostgreSQL方言直接当成兼容。

章节需已阅读，并具备网页练习通过记录或填写说明的外部练习自查，最后手动确认。外部自查不等于网页自动验证。学习计划及章节记录纳入已有备份。

## 日历拖选新建
在空白日历按住鼠标，从11:00拖到13:00后松开，会打开新事项详情，自动填写日期、11:00—13:00和120分钟。填写名称后保存。按30分钟吸附；单击不创建，冲突时灰色打叉且松开无效，Esc取消。

章节详情的每日任务与日历共用任务记录。日历调整、完成、退回清单会同步显示；每日任务完成不自动确认章节完成。

日历行距：鼠标放在时间网格，Ctrl＋滚轮向下缩小、向上放大；也可点击工具栏的减号/加号，点击百分比恢复默认75%。范围50%—175%，刷新后记住设置。缩放时保持鼠标附近时间位置，拖选、移动、调整时长继续按半小时对齐。

## 手机布局
屏幕宽度600px及以下切换为底部导航，日历显示连续3天，左右按钮切换日期。点空白时间格新建，再在全屏详情填写名称、起止时间；点已有事项可编辑，保存回日历。手机使用点击编辑时间，保留纵向滚动，不启用桌面拖拽手柄。清单、助手、设置为全屏面板，底部导航保持可用。SQL目录采用单列，点击章节跳转到详情；每日计划仍需预览确认。
手机电脑互通已加入，配置步骤见下文。


## 手机电脑互通（同一Wi-Fi）
电脑打开设置中的“手机与电脑互通”，将显示的连接地址在手机浏览器打开；点击电脑“生成手机配对码”，在手机输入12位码。配对码10分钟有效、一次使用；设备授权30天，可在电脑撤销全部连接。电脑需要开机且服务运行，数据始终存于电脑，不依赖浏览器本地保存日程。页面打开、切回前台或恢复网络时更新日程、对话与学习记录，日历冲突版本检查继续有效。
当前电脑连接地址为 http://<电脑局域网IP>:4317/connect，Wi-Fi地址改变后以设置页为准。局域网开启状态保存在电脑数据目录，桌面快捷方式后续启动也生效。当前Windows已有允许Node.js的入站规则，未新增防火墙规则。
连接为局域网HTTP，限可信Wi-Fi使用，不支持外网/手机流量。浏览器可能限制麦克风，可使用手机键盘的语音输入。真实手机连通性需要手机实际连接验证，电脑局域网地址上的配对与读写已验证。


云端部署完成后，两端直接使用同一HTTPS网址和登录密码，不需要配对码、同一Wi-Fi或电脑开机。当前是否云端以设置中的“云端同步”为准；本机地址仍是本机数据。


## 英语学习与灵活目标（2026-09-24）

英语与SQL共用总览、目录、详情的布局和白蓝黄配色，各自设置投入。英语默认当前水平，提供课堂听读、口语、词汇、写作复述四个目录。没有预填真实任务或擅自排课，确认加入清单后才创建任务。

任务详情可选时段任务或灵活任务；灵活任务不进入日历，支持一次、每日和每周目标。每日/每周完成记录保存日期，下一周期显示新的待确认状态，不生成重复日历块，也不会把未完成任务自动挪到明天。每周以周一为起点。切回时段任务后可手动安排。

课堂材料支持MP3/M4A/WAV/OGG/WebM（单文件最多512MB），配TXT/SRT/VTT或粘贴文字。带时间戳文字可回听原音；无时间戳内容显示待定位，可以填写开始秒数或播放后点标定。修改文字与时间后点击保存。本版不包含长音频自动转写或强制对齐。材料只保存一份，可填写所属课程。

词汇提取发送所选文字到已配置模型，先生成可编辑草稿，确认采用后进入词汇本。通用TXT为每行一个词，CSV包含词、释义、原句和来源；背词APP专用模板尚未找到，未宣称兼容。口语提供可复制的练习提示，进入Codex语音练习，完成后本人勾选。

已保存的英语目标、材料文本与完成记录在SQLite中；录音在同一数据目录的audio文件夹。刷新不会清除已保存内容。未点保存的表单不能当作已保存；JSON备份含学习记录，不含大型录音及API Key，迁移需另外复制audio目录。保留数据目录可跨服务重启恢复。

每日00:00的对话自动化已创建在“计划表”，以Asia/Shanghai核对刚结束的一天并列出新一天的事项，等本人逐项确认。本机不能运行时不能保证准点执行。自动化不修改日历、不自动完成任务。
