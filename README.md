# 间序 · Personal AI Planner

## 隐私与公开代码

本仓库仅发布程序代码和通用文档。日程、课程缓存、对话、学习记录、上传文件和凭证默认保存在本机 `%LOCALAPPDATA%/PersonalAIPlanner`，不会通过 Git 上传。不要把该目录或导出的备份放进仓库。

公开源码不会使本地工作台或个人数据公开。使用 AI 功能时，选定的输入仍会发送到你配置的模型服务；Canvas 连接会访问对应服务。云端部署是独立的可选配置，不会随仓库公开自动启用。

电脑端本地AI日程工作台。首版已实现并通过构建、核心自动化测试和浏览器操作检查。真实图片识别与语音转写需在设置中配置有效服务后验证。

## 运行

要求Windows及Node.js 24以上（本机使用25.6.1验证）。

```powershell
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:4317 。桌面快捷方式可由 `scripts/create-shortcut.ps1` 创建，随后双击“间序 - AI日程”启动。数据默认在 `%LOCALAPPDATA%/PersonalAIPlanner`，首启空白。

## 已实现

- 任意起日连续七天、08—24点、30分钟拖动吸附和精确录入。
- 项目、任务、部分完成、退回清单、撤销、有限学期重复课程。
- 图片／文本生成可编辑AI草稿，用户采用后事务写入；模型服务可配置。
- 语音录音及转写适配器，文字可编辑后发送。
- 本地SQLite、草稿和对话持久保存、站内跟进、备份恢复。
- Windows用户范围凭证保护，关闭网页后不提醒。

SQL学习已开放，英语保留入口；支持配对后在同一Wi-Fi内手机电脑共用数据，不含外网部署。电脑设置中生成一次性配对码，手机打开设置显示的连接地址。
